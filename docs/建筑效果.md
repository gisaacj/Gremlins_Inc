## 二、逐个建筑详解

### 2.1 银行 Bank

- **可做什么 / 是否可选**：可选。文案「If you want: invest {1}$ …」/「（可选）投资{1}$使\|增加{2}。」
  拒绝文案存在：`CellType_Bank_Skip = "{N} chooses not to invest." / "{N}选择不投資。"`
- **成本**：`Param1 = 10` → **10$**。
- **效果**：`Param2 = 10` → **收入 `|` +10**（收入是每回合结算的持续性属性，`GPlayer.GetIncome()` 基于 `Resources.Income`）。
  文案「When you invest: \|+{2}.」/ ZH「（可选）投资{1}$使\|增加{2}。」；日志 `CellType_Bank_Info = "{N} invests {1}$."`
- **代码旁证**：`GPlayer.ChangeRes` 的 `case GResourceType.Income`（`GPlayer.cs:701-727`）负责收入增减，
  其中还有银行家角色能力 `Banker_Money_Makes_Money_2` 的联动（`value += GetCharacterAbilityParam(...,3,2)`）。
- **限制**：文案与代码中没有「镇长豁免」条款。
- **一个需注意的显示分支**：`LocationDetailsPanel.cs:235-239` 对 Bank 做了特判：

  ```csharp
  if (this._cell.CellType == ECellType.Bank)
  {
      label.Caption.text = label.Caption.text.Replace("$", "");
      label.Caption.text = label.Caption.text.Replace("{1}", this._cell.Param1.ToString() + "$ + |");
  }
  ```

  即界面上银行那句会被渲染成「投资 10$ + \|」。这只是 UI 文本拼接（可能与 MOD 允许「金钱 + 收入」混合定价有关，
  `Param1` 仍是唯一的成本数值），**未确认**其确切意图；规则效果仍按 `Param1→Param2` 解读。

### 2.2 办公楼 Office

- **是否可选**：可选（`OptionalFlag = true`；`CellType_Office_Skip = "{N} chooses not to sell &."`）。
- **成本**：**1 张选票 `&`**（文案「sell 1& for {1}$」= 卖掉 1 张选票）。
- **效果**：`Param1 = 70` → **+70$**。日志 `CellType_Office_Info = "{N} sells 1& for {Z}$."`
- **限制**：文案未写「必须拥有选票」，但「sell 1&」语义上需要至少 1 张选票（推断）。
- **相关服务端字段**：`GGame.OfficeCounter`（`GGame.cs:2129`，随存档序列化，客户端内无任何读写），
  推断为「办公楼使用次数」计数，**未确认**。

### 2.3 工厂 Plant

- **是否可选**：可选（`CellType_Plant_Skip = "{N} chooses not to work for the benefit of the society."`）。
- **成本**：**跳过 1 次走牌**（文案「work by skipping 1 turn / 在此工作，跳过1次走牌」）。
- **效果**：跳过之后 **+50$（`Param1`）、-1 恶念 `^`（`Param2`）**
  文案「after skipping the turn: +{1}$, -{2}^.」/ ZH「随后，获得{1}$，但失去{2}^。」
  日志 `CellType_Plant_Info2 = "{N} works, getting {Z}$ and losing ^."`
- **注意**：`-{2}^` 是**减少恶念**（做好事），不是增加。

### 2.4 垃圾场 Junkyard（The Dump）

- **是否可选**：可选（`CellType_Junkyard_Skip = "{N} chooses not to dig through the junk."`）。
- **成本**：无金钱成本；**掷骰（1d6）**。
- **效果（骰表，`Label1..6` + `Param1..6`）**：

  | 骰点 | 文案模板 | 实际数值 |
  |---|---|---|
  | 1 | `1 = -{1}&` | **失去 1 张选票**（`Param1=1`） |
  | 2 | `2 = nothing` / 谢谢参与 | 无 |
  | 3 | `3 = nothing` / 谢谢参与 | 无 |
  | 4 | `4 = +{4}$` | **+10$**（`Param4=10`） |
  | 5 | `5 = +{5}$` | **+20$**（`Param5=20`） |
  | 6 | `6 = +{6}$` | **+30$**（`Param6=30`） |

- **额外规则（最穷玩家补贴）**：`Param2 = 30`。
  文案「If you have the least $: +{2}$ extra to any result of the dice roll.」
  / ZH「如果你是当前最穷的玩家，则掷骰结果将额外+{2}$。」
  日志 `CellType_Junkyard_Update_Bonus = "As the poorest, {N} gets the welfare of {2}$."`
  → **额外 +30$**（与骰子结果并列的一笔独立收益）。
  是否「并列」还是「仅在骰出金钱时叠加」：文案写「any result（任何结果）」→ 并列；**未确认**与骰 1（损失选票）时是否同时发放。
- **「最穷」的判定工具**：`GGame.GetMinResourcePlayers(GResourceType.Money)`（`GGame.cs:375-474`）
  返回**所有并列最小值**的玩家 ID（含自己）→ 并列最穷也算（若服务端用的是这个方法，属**推断**）。
- 注意：`Label2/Label3` 没有使用 `{3}`（`Param3 = 0`，未使用）。

### 2.5 市场 Marketplace

- **是否可选**：可选（`CellType_Marketplace_Skip = "{N} chooses not to sell *."`）。
- **成本**：**1 个齿轮 `*`（分数）**。
- **效果**：`Param1 = 200` → **+200$**。
  文案「If you want: sell 1* for {1}$.」/「（可选）以{1}$的价格出售1*。」
  日志 `CellType_Marketplace_Info = "{N} sells 1* for {Z}$."`
- 这是「分数 → 金钱」的兑换点（与 Office「选票 → 金钱」、Courthouse「金钱 → 选票」相对）。

### 2.6 监狱 Jail

> 详细机制见 §4。这里只写「到访/被捕」本身。

- **是否可选**：**不可选**（`OptionalFlag = false`）。被捕时强制进入。
- **效果**：**被捕时掷 1d6 决定刑期**（`Label1..6` + `Param1=2, Param2=3, Param3=4`）：

  | 骰点 | 文案模板 | 实际 |
  |---|---|---|
  | 1 | `1 = {3} turns` | **4 次走牌** |
  | 2 | `2 = {3} turns` | **4 次走牌** |
  | 3 | `3 = {2} turns` | **3 次走牌** |
  | 4 | `4 = {2} turns` | **3 次走牌** |
  | 5 | `5 = {1} turns` | **2 次走牌** |
  | 6 | `6 = {1} turns` | **2 次走牌** |

  独立旁证（MOD 工具文案）：
  `ModTool_JailSentenceRoll1_Label = "Turns that player must serve in the Jail when rolling 1-2"`、
  `...Roll2 = ...rolling 3-4`、`...Roll3 = ...rolling 5-6`。
- **不适用于此格的特殊条款**：无「镇长豁免」文案；反而是「镇长被逮捕。选举开始。」
  （文案 ID `17924251516795355546`：「The Governor is arrested. Elections begin.」）→ 镇长也会被捕。

### 2.7 地狱 Inferno

- **是否可选**：**不可选/强制**（`OptionalFlag = false`；弹窗只有 1 个按钮 `setOneButPanel`；
  不存在 `CellType_Inferno_Skip` 文案）。
- **成本**：**弃掉全部手牌**（`CellType_Inferno_Info = "{N} discards their hand."`）。
- **效果**：**+100$（`Param1`）、+1 恶念 `^`（`Param2`）**。
- ⚠️ **中英文案不一致**：
  - EN（`CellType_Inferno_Description`）：`Discard your hand. +{1}$, +{2}^.`
  - ZH：只有「丢弃手牌。」（没有 `+{1}$，+{2}^` 部分；`Chinese.txt` 中该 UIN 行即为此文本）
  → 中文版文案缺一段，但**数据里的 `Param1=100 / Param2=1` 仍存在**，因此按「弃手牌 → +100$、+1恶念」记录。
  最终以服务端执行器为准，而该执行器不在本程序集内 → **未确认（文案层面）**。

### 2.8 赌场 Casino

- **是否可选**：可选（`CellType_Casino_Skip = "{N} chooses not to gamble."`）。
- **成本**：掷骰（1d6），无前置花费。
- **效果（骰表）**：`Label1..6` 中 1~3 为负、4~6 为正，参数 `Param1..6 = 100,50,25,25,50,100`：

  | 骰点 | 文案模板 | 实际 |
  |---|---|---|
  | 1 | `1 = -{1}$` | **-100$** |
  | 2 | `2 = -{2}$` | **-50$** |
  | 3 | `3 = -{3}$` | **-25$** |
  | 4 | `4 = +{4}$` | **+25$** |
  | 5 | `5 = +{5}$` | **+50$** |
  | 6 | `6 = +{6}$` | **+100$** |

  日志：`CellType_Casino_Update1 = "...and wins {Z}$!"`、`Update2 = "...and loses {Z}$!"`。
- **附加规则**：文案「If you lose more $ than what you have: +2^.」/「如果你输掉的$多于所拥有的：+2^。」
  → **输掉的金额超过持有金钱时，+2 恶念 `^`**。
  金钱有下限保护（`GPlayer.ChangeRes`，`GPlayer.cs:472-476`）：

  ```csharp
  case GResourceType.Money:
      if (this.Resources.Money + value < 0) value = -this.Resources.Money;  // 不会变负
  ```
  → 赌场输钱最多把钱扣到 0，然后按上文加 2 恶念（触发口径见「未确认项」第 7 条）。

### 2.9 法院 Courthouse

- **是否可选**：可选（`CellType_Courthouse_Skip = "{N} chooses not to take away &."`），
  且有多一步选择：`CellType_Courthouse_Select = "Choose the player from whom to take away &."`
- **成本**：`Param1 = 40` → **40$**；限制：文案明写「(**you must have {1}$**)」→ **必须持有 40$ 才能使用**。
- **效果**：`Param2 = 1` → **从任选玩家处夺走 1 张选票 `&`**（被夺者可任意选，包括镇长）。
  文案「If you want: -{1}$, take away {2}& from any player of your choice (you must have {1}$).」
  日志 `CellType_Courthouse_Info = "{N} pays {1}$ and takes away {2}& from..."`、`Update = "...{Z}!"`
- **限制**：文案没有写「被夺者至少要有一张选票」；这一约束是否存在**未确认**。

### 2.10 藏宝阁 Treasure

- **是否可选**：**强制**（`OptionalFlag = false`；无 `CellType_Treasure_Skip` 文案；弹窗 `setSixLabPanel`）。
- **成本/效果**：掷 1d6，直接得钱（`Param1..6 = 10,25,50,100,150,200`）：

  | 骰点 | 文案 | 实际 |
  |---|---|---|
  | 1 | `1 = +{1}$` | **+10$** |
  | 2 | `2 = +{2}$` | **+25$** |
  | 3 | `3 = +{3}$` | **+50$** |
  | 4 | `4 = +{4}$` | **+100$** |
  | 5 | `5 = +{5}$` | **+150$** |
  | 6 | `6 = +{6}$` | **+200$** |

  日志 `CellType_Treasure_Update = "...and finds {Z}$."`
- 角色联动（非建筑规则，供参考）：收藏家能力 `Collector_Archaeology`、
  永久卡 `Perm_TreasureMoney`、`EAction.TreasureReroll`（重掷）存在于 `EAction.cs`。

### 2.11 天界 Astral（The Astral Plane）

- **是否可选**：可选（`CellType_Astral_Skip = "{N} chooses not to rest."`）。
- **成本**：**跳过 1 次走牌**；之后还要 **-2 恶念 `^`**（`Param2 = 2`，「支付{2}^」）。
- **效果**：跳过之后 **从整副牌抽 3 张（`Param1 = 3`），可保留其中 1 张**。
  文案「rest by skipping 1 turn; after skipping the turn: -{2}^, draw {1} cards from the deck – you may choose 1 card to keep.」
  日志 `CellType_Astral_Info2 = "{N} rests, losing {Z}^ and choosing a card..."`、`Update = "...the choice is made!"`
- **相关服务端字段**：`GPlayer.AstralCounter`（`GPlayer.cs:2102`，序列化），推断与天界使用/休息计数有关，**未确认**。
- 角色联动：政客 `Politician_Astral_Club` / `Politician_Astral_Club_2`（后者还能让**银行→天界**直连，
  见 `CD.cs:10934-11073` 的 `CheckAstralLift/RemoveAstralLift`），永久卡 `Perm_AstralElevator`。

## 五、关于「每回合只能用一次」

**结论：本程序集无法证实「每建筑每回合一次」这条规则，也无法证伪。** 相关证据如下：

   （对 `E:\code\小魔怪\test` 全目录 `*.cs` 搜索 `BankVisited|OfficeVisited|…|AstralVisited`，
