# 移动端（Android APK）构建说明

> 状态：**已打通，实测能产出可安装的 APK**。
> debug 5.01 MB；release（未签名）3.53 MB。
> 环境已装在本机 D 盘，一条命令即可重新打包。

## 一、一条命令打包

```powershell
cd E:\code\小魔怪-push
node tools\build-apk.mjs            # 默认 debug
node tools\build-apk.mjs release    # release（未签名）
```

脚本做三件事：`tsc -b` + `vite build` → `cap sync android` → `gradle assembleDebug`，
最后打印 APK 的**绝对路径与体积**。

产物：

```
client\android\app\build\outputs\apk\debug\app-debug.apk              (5.01 MB)
client\android\app\build\outputs\apk\release\app-release-unsigned.apk (3.53 MB)
```

装到手机（debug 包可直接装）：

```powershell
D:\devtools\android-sdk\platform-tools\adb.exe install -r `
  client\android\app\build\outputs\apk\debug\app-debug.apk
```

> **为什么用 Node 脚本而不是 `npm run`**：
> 本机 `npx.ps1` / 一般 `.ps1` 被执行策略拦住（`PSSecurityException`），
> 且工程路径含中文，走 shell 容易被再解释一遍。脚本直接用
> `node <tsc>` / `node <vite>` / `java -classpath <gradle-launcher>`
> 调用，绕开这两类问题。

### 为什么必须换镜像

本机网络下若干官方源**不可达**，实测结果：

| 源 | 结果 |
|---|---|
| `services.gradle.org` | ✗ 超时 → 改用 `mirrors.cloud.tencent.com/gradle` |
| `repo.maven.apache.org`（Maven Central） | ✗ 超时 → 改用 `maven.aliyun.com/repository/{google,central,public}` |
| `api.adoptium.net`（JDK 下载） | ✗ 超时 → 改用 `mirrors.tuna.tsinghua.edu.cn/Adoptium` |
| `dl.google.com`（Android SDK） | ✅ 可达 |

因此：
- `client/android/gradle/wrapper/gradle-wrapper.properties` 指向腾讯镜像；
- `client/android/build.gradle` 里 **阿里云镜像优先**，官方源留作兜底。

> 这些改动**入库了**。如果你在别的网络环境下构建失败，可以把镜像改回
> `google()` / `mavenCentral()`（两处 `repositories` 块）。

### 中文路径问题

AGP 默认拒绝在**含非 ASCII 字符**的路径下构建
（本工程是 `E:\code\小魔怪-push`）。已在 `client/android/gradle.properties`
里加 `android.overridePathCheck=true` 放行，实测可正常构建。

## 三、移动端界面适配

原先窄屏只做了"主体改竖向 + 侧栏压成 200px 横条"，结果要紧信息全被挤掉。
本轮重做（集中在 `client/src/styles/mobile.css`）：

| 问题 | 修法 |
|---|---|
| 侧栏在地图下方又占 200px，手机地图只剩两三行高 | 侧栏 / 暴乱面板改为**可开合浮层抽屉**（顶栏 ☰ / ◆ 开关，点空白处收起），地图独占空间 |
| `.action-panel` 是 `position: fixed; bottom: 140px` 魔法数字，直接压在地图上 | 改为 `position: absolute` 贴在**棋盘容器底部**，`max-height` 超出时内部滚动 |
| 棋盘接近正方形（viewBox 120×117），竖屏按宽度缩放导致上下大片空白 | 改为**按高度铺满**、宽度不够时左右拖动，并允许**双指缩放** |
| 手牌卡片固定 110×160，一屏只看到两三张 | 宽度走 `--card-w` 变量，按屏宽降到 92 / 80 / 78px；横屏进一步压扁 |
| 刘海 / 小白条遮挡 | 全部固定元素接 `env(safe-area-inset-*)`；`index.html` 已有 `viewport-fit=cover` |
| 移动浏览器地址栏收起时底部内容被顶出屏幕 | 支持时用 `100dvh`（动态视口高度），不支持则回退 `100%` |
| 顶栏元素换行、`镇长：xxx` 挤成两行 | 单行 + 横向滚动 + 文字省略 |
| 输入框会触发 iOS 自动放大 | 移动端 `input` 字号统一 ≥16px；出价输入加 `inputMode="numeric"` 弹数字键盘 |
| 触控目标偏小 | 按钮 `min-height` 38px、关键操作 44px |

断点用 **900px**（而不是原来的 768px）：768~900 这一段横屏手机同样需要抽屉式布局。
横屏且高度 ≤500px 时另有一套更扁的规则（手牌占 132px 太浪费）。

菜单 / 房间 / 选角 / 结算页也补了安全区与滚动，选角网格在窄屏收窄到
`minmax(150px, 1fr)`。

## 四、装到手机后要做的第一件事

打开 App → 主菜单 → **服务器** 一栏填写运行服务端那台电脑的
**局域网 IP 与端口**（例如 `192.168.1.10:3000`），保存后会重新加载并连接。
手机与电脑需在同一局域网，且电脑防火墙放行该端口。

> 原生壳里页面跑在 WebView 自己的 `https://localhost` 上，
> 所以**不能**靠 `window.location.origin` 推服务端地址 —— 必须手填。
> 未填时会明确报错，不会静默连 localhost。
