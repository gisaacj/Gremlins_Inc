## 二、本轮修掉的移动端阻断问题

**现象**：APK 装上后**永远连不上服务端**，且看不出原因。

**根因**：原实现取连接地址的方式是

```ts
const url = import.meta.env.VITE_SERVER_URL
         || (import.meta.env.DEV ? '/' : window.location.origin);
```

在 Capacitor 原生壳里，页面跑在 WebView **自己的本地 scheme** 上
（Android 默认 `https://localhost`），所以 `window.location.origin`
指的是**设备本机**，不是我们的服务器。
`capacitor.config.ts` 里那句"实际部署时在 App 内设置中填写服务端 IP"
说明当时就留了这个坑没填。

**修复**（`client/src/net/socket.ts`）：

1. 新增运行时配置：地址存在 `localStorage`（键 `gremlins.serverUrl`），
   玩家可在主菜单「服务器」一栏填写（如 `192.168.1.10:3000`）。
2. `normalizeServerUrl()` 允许裸 `IP:端口` 输入，自动补 `http://`。
3. **原生壳且未配置时明确报错**，不再静默连 `localhost`：
   `getSocket()` 抛出"尚未配置服务端地址：请在「设置」里填写服务器 IP 和端口"，
   `Menu` 页面把这条错误显示给玩家。
4. 网页版行为不变（默认同源部署，无需配置）。
5. `import.meta.env` 用 optional 取值，避免在非 Vite 环境（Node 测试）
   直接取属性抛错。

## 三、构建环境缺口（本机实测）

| 组件 | 要求 | 本机现状 |
|---|---|---|
| **JDK** | Capacitor 6 需要 **17** | 只有 `C:\Program Files\Java\jdk-15.0.2` 与 `jre1.8.0_291` ❌ |
| **Android SDK platform** | 需 `platforms/android-3x` | `C:\Program Files (x86)\Android\android-sdk\platforms\` **为空** ❌ |
| **Android build-tools** | 需 `build-tools/3x.x.x` | 同上的 `build-tools\` **为空** ❌ |
| SDK tools | — | 仅 2015 年旧版 `tools`（Pkg.Revision 24.4.1） ⚠️ |
| platform-tools / adb | — | 在 `D:\platform-tools-latest-windows\platform-tools\adb.exe`（不属该 SDK） ⚠️ |
| 网络 | 需 `dl.google.com` | 可达 ✅ |

**结论**：需要下载约 500MB+（JDK 17 + platform-tools + platform-34 + build-tools）。

## 四、环境补齐后的构建步骤

```powershell
# 0) 设好环境变量（示例路径，按实际改）
$env:JAVA_HOME  = 'C:\Program Files\Java\jdk-17'
$env:ANDROID_HOME = 'C:\Android\Sdk'

# 1) 构建 web 资源（Capacitor 的 webDir 指向 client/dist）
cd E:\code\小魔怪-push\client
& 'D:\nodejs\npm.cmd' run build

# 2) 生成 Android 平台（首次）
& 'D:\nodejs\npm.cmd' exec cap add android

# 3) 同步 web 资源与插件
& 'D:\nodejs\npm.cmd' exec cap sync android

# 4) 打包 debug APK
cd android
.\gradlew assembleDebug
# 产物: client\android\app\build\outputs\apk\debug\app-debug.apk
```

## 五、装到手机后要做的第一件事

打开 App → 主菜单 → **服务器** 一栏填写运行服务端那台电脑的
**局域网 IP 与端口**（例如 `192.168.1.10:3000`），保存后会重新加载并连接。
手机与电脑需在同一局域网，且电脑防火墙放行该端口。
